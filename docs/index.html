Open Claim

This shows where a claim came from and how it travelled. It does not say whether it is true, and it does not judge the person who wrote it.

Status Built and working offline: a chain of hops where each one names who cited whom; the origin marked, a chain that runs out marked untraced; citations, repetitions and independent sources counted and shown as three separate numbers; a broken link kept with the date it was last read; and a red-flag reader that names the technique and quotes the sentence.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: any search or fetching. The app does not look anything up — you record what you found, and it never presents an old chain as a current one, because it cannot check.

What it does

  • Records a claim and the hops it travelled, each hop naming who cited whom.
  • Counts citations, repetitions and independent sources — three numbers that differ, which is the whole point.
  • Marks the origin, and marks a chain that runs out as untraced rather than assuming the last thing it found is the source.
  • Keeps a broken link, with the date it was last read.
  • Flags manipulation techniques in a passage, naming the technique and quoting the sentence so you can disagree with the flag.

What it will not do

  • Say whether a claim is true. It shows the chain; the judgement stays with you.
  • Judge the author. It flags techniques, not people.
  • Offer an empty flag list for text it did not read. An empty list only ever means “read, and clean”.
  • Assume the last hop is the origin. A chain that runs out is marked untraced.
  • Shorten a chain that fails to parse. It is shown as broken at the link that failed.
  • Use a key or a network. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputA claim with no hops → “no source found”, with the search terms used. A passage too short to read → refused, with no flag list at all.
No networkNothing changes; the app never looked anything up, so it never presents an old chain as a current one.
Storage full or unavailableThe trace is not saved and the app says so; the chain stays on screen for the session.
Corrupt saved stateReported and offered for export; a chain that fails to parse is shown as broken at the link that failed.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js — the spec's countable “done means” is asserted there.
