Where it came from, and how many times it went round.

Ten outlets running the same paragraph is not ten sources. It is one source, ten times — and the difference is the only thing this app is about.

Paste a claim, add each citation as a hop, and Claim walks the chain back. It counts three things that people conflate: how many citations there are, how many repetitions that makes, and how many independent origins are left when you get to the end.

And the other half

Red Flag reads a passage and names the technique being used — the false dilemma, the loaded question, the appeal to a nameless authority — quoting the sentence it found it in. It never says whether the claim is true.

“A passage it has not read returns no list at all, because an empty list reads as a verdict.”

What it refuses

It will not tell you a claim is true or false, will not judge the author, and will not assume the last hop is the origin. A chain that runs out is marked untraced rather than guessed at.
